# Brag Plan: InsidCode

## What is this app?
InsidCode is a focused programming practice platform designed to build foundational algorithmic intuition, recursion mastery, and multi-language problem-solving skills across 330+ structured challenges and real-time 1v1 Duels before touching DSA.

## The angle
Developers often jump straight to memorizing LeetCode solutions without mastering foundational programming logic. InsidCode fixes that with a strict logic-first curriculum, browser-based sandboxed compiler execution across 5 languages, and live head-to-head Duel matches.

## Hook (first 2-3 seconds)
Big, bold, fast-in display text over a glowing IDE grid: **"DON'T MEMORIZE DSA."** followed by **"MASTER LOGIC FIRST."**

## Key moments (the middle)
- **330+ Curated Challenges across 6 Phases**: Visual breakdown of Warmup, Math, Recursion, Arrays, Strings, and Mixed Logic.
- **Multi-Language Sandbox**: Instant execution across Java, Python 3, C++, C, and JavaScript in Monaco.
- **Live 1v1 Duel Arena**: Best of 3 real-time competition with synchronized round timers and live match telemetry.

## Outro / punchline
The terminal prints `Accepted: 100% Tests Passed` -> InsidCode logo reveals with **"insidcode.vercel.app — Built for disciplined logic growth."**

## User flow worth showing
1. Browse 6-Phase Curriculum (330+ challenges)
2. Solve in Monaco Editor with live test case validation
3. Battle in 1v1 Duel Arena with live opponent scoring
